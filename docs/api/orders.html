API /orders

Наряды — задачи на работы с буртом: вентиляция, сушка, перемещение. POST /v1/orders создаёт наряд, PATCH /v1/orders/{id} меняет статус (new → in_progress → done).

{
  "id": 42,
  "type": "ventilation",
  "zone": "center",
  "reason": "T2 > 25 C for 3 cycles",
  "status": "in_progress"
}

Наряд, созданный автоматикой, содержит ссылку на событие тревоги в поле alert_id.
