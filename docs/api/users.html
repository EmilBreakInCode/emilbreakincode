API /users

GET /v1/users — список учётных записей (только роль admin). POST /v1/users — создание оператора.

[
  {
    "id": 1,
    "login": "operator1",
    "role": "operator",
    "active": true
  }
]

Поля: login (3–32 символа), role (operator | admin), active. Пароль задаётся отдельным запросом POST /v1/users/{id}/password.
