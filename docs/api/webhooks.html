API /webhooks

POST /v1/webhooks подписывает внешний URL на события alert.raised, alert.cleared, order.done. Доставка: POST с JSON-телом, таймаут 5 с, три повтора с экспоненциальной задержкой.

{
  "event": "alert.raised",
  "sensor": "T2",
  "value": 26.8,
  "threshold": 25.0,
  "ts": "2026-11-17T09:15:00Z"
}

Подпись тела — HMAC-SHA256 в заголовке X-ZM-Signature (секрет выдаётся при создании подписки).
