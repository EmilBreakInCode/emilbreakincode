Настройка

Основной файл конфигурации config.json задаёт интервал опроса и пороги тревог. Значения по умолчанию соответствуют требованиям хранения продовольственного зерна.

{
  "poll_interval_sec": 900,
  "thresholds": {
    "temperature_c": 25.0,
    "humidity_pct": 17.0
  },
  "alert_channels": ["web", "email", "webhook"]
}

После изменения конфигурации выполните zmctl config reload — перезапуск сервера не требуется.
