Установка

Комплект поставки: датчики температуры T1–T4 и влажности W1–W2, шлюз ZM-G1 (RS-485 → Ethernet), серверная часть ZernoMonitor Core.

Порядок монтажа

  1. Разместите датчики по схеме бурта: три уровня по высоте, центр и периферия;
  2. Подключите датчики к шлюзу шиной RS-485 (витая пара, терминаторы 120 Ом);
  3. Подключите шлюз к локальной сети и задайте ему статический IP;
  4. Разверните ZernoMonitor Core на сервере в той же сети;
  5. Добавьте шлюз в веб-интерфейсе: Настройки → Шлюзы → Добавить.

Проверка связи

zmctl gateway ping 192.168.1.50
# OK: 6 sensors online, rssi -47 dBm
