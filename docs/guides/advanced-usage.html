Продвинутое использование

Зоны бурта

Датчики группируются в зоны (центр, периферия, подкровельное пространство). Пороги можно задавать per-zone: под кровлей конденсат опаснее, поэтому порог влажности там ниже на 1–2 п.п.

Автоматика вентиляции

Правило «если T зоны > порога в течение 3 циклов — включить вентиляцию» создаётся в разделе Автоматика. Наряд на вентиляцию оформляется через API нарядов и исполняется контроллером шлюза.

Выгрузка в учётные системы

Ежесуточный CSV-отчёт выгружается по cron-задаче zmctl export daily и может отправляться вебхуком (см. вебхуки).
