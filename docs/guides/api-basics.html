Основы API

Базовый URL: https://api.zernomonitor.example/v1. Все ответы — JSON в UTF-8. Ошибки возвращаются с кодами 4xx/5xx и телом {"error": "...", "code": ...}.

curl -s https://api.zernomonitor.example/v1/readings?sensor=T2&limit=5
# [{"ts":"2026-11-17T09:00:00Z","t_c":21.4,"w_pct":14.2}, ...]

Пагинация: параметры limit (по умолчанию 100) и offset. Подробности по ресурсам — в разделе REST API.
