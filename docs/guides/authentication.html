Аутентификация

Веб-интерфейс использует сессионные cookie и роли: operator (просмотр и наряды), admin (настройка и пользователи). REST API аутентифицируется ключом в заголовке X-API-Key.

curl -H "X-API-Key: zm_live_9f2c71" https://api.zernomonitor.example/v1/users

Ключи выпускаются в разделе Настройки → API-ключи и хранятся только в хешированном виде. Компрометированный ключ отзывается немедленно.
